The Excalidraw editor ({{EXCALIDRAW}}) with the extras of the scratchy R package: sticker libraries, Open Peeps people, style presets, Mermaid diagrams, self-drawing SVGs and Obsidian .excalidraw.md files. Open them from the ✎ button next to Library.

Everything stays in this browser: your drawings are kept here between visits, and nothing is uploaded. Once loaded, it works offline, and you can install it as an app.

  • All boards Ctrl+P: named tabs, folders, search inside drawings, history, 30-day trash, and full workspace ZIP backup and restore. Closing a tab keeps its drawing. Browser autosave is separate from a backup or a saved external file.
  • Projects Ctrl+\ shows the explorer: each heading of a project's Markdown Source is a canvas. Present plays the canvases as slides; Export… makes PowerPoint, PDF or a project ZIP.
  • Open Ctrl+O: .excalidraw, .excalidraw.md, and SVG or PNG images saved with the drawing inside. You can also drop files on the canvas.
  • Save Ctrl+S, Save as Ctrl+Shift+S: the format follows the file name.

From R: install.packages("scratchy", repos = "https://jossammil.r-universe.dev") turns ggplot2 charts into editable drawings. R documentation · Credits and licences.
