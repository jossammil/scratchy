# Roadmap after the workspace release

Implemented: the persistent vault explorer, nested project canvases, master Markdown, browser slideshow, editable-text PowerPoint, rendered PDF and portable project ZIP. See [Projects and slides](projects-and-slides.md).

The items below extend the same board collection and editor model; they are not separate competing workspace designs.

| Order | Feature | User workflow and completion criteria |
|---|---|---|
| 1 | Searchable assets | Find existing stickers by name or concept, insert them into the active board, and retain the library offline. Add selected domain packs after the bundled assets work. |
| 2 | Richer Markdown and Quarto workflows | Add tables, equations, slide notes, richer inline formatting and explicit Quarto/R rendering. Define source ownership and execution separately from the current plain Markdown/canvas round trip. |
| 3 | Automatic folder mirroring | Choose a local folder in supported browsers; see whether copying is active or paused, restore permission after restart, and catch up missed changes. Keep ZIP backup in every browser. |
| 4 | Linked detail boards | Open a supporting board from a shape, return through breadcrumbs, and preserve stable links through renames and backup/restore. |
| 5 | Side-by-side editing | Open two boards with independent viewports. Keyboard commands, exports and file saves act on the explicitly focused pane. |
| 6 | Faster diagram creation | Add connected steps and process/table templates using native Excalidraw shapes. Add Mermaid preview and retained source with explicit regeneration behavior; evaluate browser D2 independently. |
| 7 | Richer retrieval | Add typo tolerance and organization filters while preserving predictable exact-match ranking. |
| 8 | Collaboration and presentation extras | Evaluate live collaboration, optional AI handoff, video and animated actors after persistence and recovery are established. Define conflict/reconnection and export behavior before adding these. |
